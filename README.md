# 気分日記（Mood Diary）

鬱の時でも続けられる、できるだけ簡単な気分記録アプリ。個人開発のポートフォリオ作品です。

## 背景

日記アプリはすでに多くの類似サービスが存在するレッドオーシャンな領域です。機能で差別化するのではなく、次の2点を軸にしました。

- **記録の負荷を極限まで下げる**：4色のマスをタップするだけで記録が完了する
- **サボったことを責めない**：連続記録日数ではなく、累計記録日数で育つ要素にすることで、記録が途切れても積み上げが消えない設計にする

## 気分レベルの定義

| レベル | ラベル | 背景色 | 目 | 口 |
|---|---|---|---|---|
| 3 | 最高 | `#7BC67E` | ^ ^ | 上に凸のカーブ |
| 2 | 普通 | `#F6CB4E` | ・ ・ | 一直線 |
| 1 | 悪い | `#F2A74B` | ・ ・ | 下に凸のカーブ |
| 0 | 最悪 | `#F17171` | × × | 下に凸のカーブ |

顔のパーツは背景色によらず `#4A3728` で統一。角丸正方形のマスそのものが表情になり、背景と別レイヤーのキャラクターを持たないシンプルな構成。

## 育成要素

累計記録日数に応じて、キャラクターの頭に芽が生え、花になっていく。今日のマスとホーム画面のキャラクターにのみ反映し、カレンダーの過去日には反映しない。

| 累計日数 | 状態 |
|---|---|
| 0〜2日 | なし |
| 3〜6日 | 小さな芽 |
| 7〜13日 | 双葉 |
| 14〜29日 | 蕾 |
| 30日〜 | 開花 |

## 画面構成

1. 記録画面 - 今日の気分（4色タップ）＋ひとことメモ（任意）＋タグ（任意）。カレンダーや今月のメモから過去の日付を選ぶと、その日の記録の編集・削除もできる
2. カレンダー画面 - 月間、記録済みの日はその日の色+表情、今日のマスのみ育成キャラクターを表示
3. 記録一覧画面 - 月ごとの色別カウント、メモ一覧

## 技術スタック

- React + TypeScript
- Vite
- localStorageによるデータ永続化（記録・編集・削除、いずれもブラウザ内に保存）
- GitHub Pages（`gh-pages` パッケージによるデプロイ）

## 開発

```
npm install
npm run dev
```

## GitHub Pagesへのデプロイ

```
npm run deploy
```

初回のみ、リポジトリの Settings → Pages で Source を `gh-pages` ブランチに設定してください。
公開URLは `https://<GitHubユーザー名>.github.io/mood-diary-web/` になります。
リポジトリ名を `mood-diary-web` 以外にした場合は、`vite.config.ts` の `base` もあわせて変更してください。
